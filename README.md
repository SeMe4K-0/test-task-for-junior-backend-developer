# Task Service

Сервис для управления задачами с HTTP API на Go.

## Требования

- Go `1.23+`
- Docker и Docker Compose

## Быстрый запуск через Docker Compose

```bash
docker compose up --build
```

После запуска сервис будет доступен по адресу `http://localhost:8080`.

Если `postgres` уже запускался ранее со старой схемой, пересоздай volume:

```bash
docker compose down -v
docker compose up --build
```

Причина в том, что SQL-файл из `migrations/0001_create_tasks.up.sql` монтируется в `docker-entrypoint-initdb.d` и применяется только при инициализации пустого data volume.

## Периодические задачи

Реализована поддержка периодических задач. При создании задачи с настройками периодичности (`recurrence`) создается запись-шаблон и генерируются отдельные экземпляры задач на каждую дату выполнения.

### Типы периодичности
- **Daily**: Каждые N дней (задается через `interval`).
- **Monthly**: Каждое N-е число месяца (задается через `day`). Если числа нет в месяце (например, 31-е), месяц пропускается.
- **Specific dates**: Набор конкретных дат (задается через `dates`).
- **Parity**: Четные или нечетные дни месяца (задается через `parity`: "even" или "odd").

### Особенности реализации и допущения
1. **Предгенерация**: Мы выбрали подход с физическим созданием всех экземпляров задач в БД. Это позволяет независимо менять статус каждой конкретной задачи (например, отметить обход за вторник как выполненный, не влияя на среду).
2. **Лимиты безопасности**: Чтобы избежать бесконечного создания записей, генерация ограничена:
   - Максимальный период: 1 год от `start_date`.
   - Максимальное количество задач за один раз: 366.
3. **Транзакционность**: Шаблон и все его экземпляры создаются в рамках одной транзакции.
4. **DueDate**: В модель задачи добавлено поле `due_date`, указывающее на дату выполнения.
5. **Независимость**: После генерации каждая задача живет своей жизнью. Удаление шаблона (через `ON DELETE CASCADE` в БД) удалит все связанные задачи, но изменение шаблона в текущей реализации не меняет уже созданные задачи (это осознанное упрощение для тестового задания).

### Пример запроса на создание ежедневной задачи
```json
POST /api/v1/tasks
{
    "title": "Ежедневный обзвон",
    "description": "Обзвонить пациентов",
    "status": "new",
    "recurrence": {
        "type": "daily",
        "interval": 1,
        "start_date": "2026-04-10T00:00:00Z",
        "end_date": "2026-05-10T00:00:00Z"
    }
}
```
